# Шпаргалка для демонстрации (5–7 минут)

Подготовка (за 10 минут до): активировать venv, `python portal.py`, открыть http://127.0.0.1:8000.

1. **Постановка** (30 с): две биржи → одна база → портал → планировщик.
2. **Портал**: сортировка по сумме; фильтр биржа = CCX; период; поиск продавца по названию и по БИН;
   диапазон суммы; брокер; место поставки. Показать, что страница не перезагружается. «Сбросить». «Excel».
3. **Состояние данных**: журнал запусков, количество записей, даты по биржам.
4. **Ручной запуск**: `python scheduler.py --once --only ccx` → затем обновить журнал. Показать `config.ini` (время запуска).
5. **Качество данных**: `python load.py check` → расхождений 0. Рассказать про найденную потерю одинаковых строк.
6. **БД**: `docs/DATABASE.md`, схема, индексы, дамп `trades_dump.sql`, `python dump_db.py --restore`.
7. **Честно об ограничениях**: нет объёма/единицы; базис ETS из названия; автозагрузка ETS — результат на реальном сайте.

Вопросы, к которым стоит подготовиться: почему SQLite; как устроена дедупликация; как защищён поиск от SQL-инъекций
(параметры + белый список сортировки); что будет, если сайт изменится (запись `error`/`warning` в журнале, данные не теряются).
