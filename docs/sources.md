# Анализ источников

## ETS (ets.kz)
- Данные публикуются файлами Excel (.xlsx), один файл на торговый день, на страницах
  «Документы → Итоги торгов → <год> → <месяц>». API нет.
- Колонки B..Q: покупатель, БИН, брокер, продавец, БИН, брокер, товар, ТН ВЭД, код, число сделок,
  цены (открытия, закрытия, макс., мин., средняя), сумма. Последняя строка «Итого» используется как
  контрольная сумма и в сделки не попадает. Читаем по позиции колонок, дату — из заголовка листа.
- Объёма и единицы измерения в файле нет. Базис поставки отдельной колонкой не дан — извлекается из
  названия товара (EXW, FCA, CPT…).
- Автозагрузка: `ets_fetch.py` обходит страницу года и страницы месяцев, скачивает .xlsx.

## Каспий (ccx.kz)
- Итоги торгов — серверно-рендеренная HTML-таблица (16 колонок) с параметрами в URL:
  `date_from`, `date_to`, `page`, `lang`. Скрытого JSON-API для этой таблицы найдено не было
  (запрос `/api/schedule/today` относится к расписанию торгов, а не к итогам).
- Строка без кода ТН ВЭД с оборотом — итог дня (в `daily_totals`). БИН приклеен к названию участника
  и отделяется регулярным выражением.
- Пагинация: страницы перебираются до пустой или повторившейся; пауза 1,5 с между запросами.
- Объёма и единицы измерения нет.

## Общее
Оба источника приводятся к одной записи (поля `trades`), поэтому портал не различает формат источника.
