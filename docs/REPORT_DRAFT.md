# Отчёт по практике (черновик — отредактируйте под себя)

**Тема:** сбор и анализ итогов торгов бирж ETS и Каспий (CCX). **Срок сдачи:** 12.11.2026.

## 1. Цель и задачи
Собрать итоги торгов двух бирж, сложить в общую реляционную базу, сделать веб-портал с фильтрами и
ежедневный планировщик сбора.

## 2. Что сделано
- Парсер ETS (Excel) и парсер CCX (HTML-таблица с пагинацией).
- База SQLite: справочники, таблица сделок, оборот дня, журнал запусков, 11 индексов, дедупликация.
- Сверка суммы сделок с оборотом дня, объявленным биржей: расхождений нет (19 дней).
- Портал: таблица, сортировка, пагинация, все фильтры из ТЗ без перезагрузки страницы, страница состояния,
  выгрузка в Excel.
- Планировщик: расписание в `config.ini`, ручной запуск, повтор при неудаче, журнал в БД.
- Автотесты (8), дамп базы, README.

## 3. Как работал (этапы)
Анализ источников → парсеры → схема БД → загрузка и сверка → портал → планировщик → документация.

## 4. Что не получилось / ограничения
- Ни одна биржа не публикует объём и единицу измерения — этих полей в базе нет.
- Базис поставки ETS извлекается из названия товара регулярным выражением; если его там нет, поле пустое.
- Автозагрузка ETS проверена на тестовом сайте-имитации, который я сам написал, и на файлах, скачанных
  вручную. Реальная структура страниц ets.kz могла отличаться — **укажите здесь результат запуска на реальном сайте**.
- Данные в базе охватывают ограниченный период, а не весь архив бирж.

## 5. Ошибки и уроки (реальные)
1. Одинаковые строки в один день схлопывались дедупликацией (потерялись сделки 08.09 на CCX). Нашла сверка
   с оборотом дня. Урок: контрольная сумма с источника — лучший способ поймать потери данных.
2. Кириллица в заголовке User-Agent вызвала `UnicodeEncodeError`. Урок: заголовки HTTP — только ASCII.
3. Кнопка «Сбросить» не работала: `id="reset"` перекрыл `form.reset` в JavaScript. Найдено тестом в браузере.
4. Файлы, скачанные повторно, получали имена вида `file (1).py`, и Python не находил модули. Урок: проверять имена файлов.
5. Установился не тот пакет (`unicorn` вместо `uvicorn`), поэтому портал переведён на стандартную библиотеку.
6. Частичный сбой при загрузке ETS сначала обнулял результат всего запуска; теперь статус `warning`, а успешные файлы сохраняются.
7. Тест, сравнивавший сумму сделок одной сохранённой страницы с оборотом дня, был неверен: страница содержит часть дня.

## 6. Использование ИИ
Проект выполнялся с помощью ИИ-ассистента (Claude): он писал код и документацию, а я запускал его
на своём компьютере, проверял результаты, снимал скриншоты и сообщал об ошибках. Ассистент не имел доступа
к сайтам бирж из своей среды, поэтому структура источников выяснялась по моим скриншотам и сохранённым файлам.
Я понимаю назначение каждого модуля и могу объяснить его (см. `docs/DEMO.md`).

## 7. Что можно улучшить
